写真版ECサイト（GitHub Pages用）

1. GitHubで新しいPublicリポジトリ traditional-craft-photo を作成します。
2. このフォルダ内の index.html と README.txt をリポジトリ直下にアップロードします。
3. Settings > Pages で Source を Deploy from a branch、Branch を main、Folder を /(root) にして Save します。
4. 公開URLは https://ciel87519-pixel.github.io/traditional-craft-photo/ となる想定です。

画像はHTML内に埋め込まれているため、別途画像ファイルをアップロードする必要はありません。
このサイトと掲載データは公開されるため、個人情報や非公開情報を含めないでください。
